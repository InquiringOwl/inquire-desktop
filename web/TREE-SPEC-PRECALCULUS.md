## The interaction rule (Devon, Oct 2026) — every Precalculus lab
Read `docs/categorical/PLANE.md` § The interaction rule. In short:
- **Chart and angle labs**: every point that defines the figure is a handle (`k.drag`): vertices, foci, intercepts, endpoints, data points, the tip of a vector, a rotation angle's ray. A point that belongs to a curve slides **along** it (`on: f`, or `path` for parametric/polar/conic curves). The readout, equation and steps recompute live as it moves.
- **Number and variable labs**: every number the computation uses is a scrubbable, typeable `k.vars` value shown **inside the equation or matrix itself** (`S.html(key)` in `k.eqline`, the readout or a steps panel). Change a number and everything downstream (graph, solution steps, answer) is recomputed for the new problem.
- One source of truth: a handle and a number that describe the same quantity are the same state (dragging the vertex changes h and k in the equation; scrubbing h moves the vertex).
- "Your turn" modes: the learner may still change the problem's numbers; `k.guard` the answers of the current numbers and re-guard on every change.
Each node below names its **handles** (⇄) and **numbers** (#). Writers may add more; never fewer.

## Kit first (done before wave 1, in `web/kits/subjects/precalc.js`; tests `tests/precalc.test.js`; check helpers `checks/_lib/precalc.py`)
Writers must not re-invent these; the API is in `docs/subjects/MATH.md` § Precalculus.
- **Matrices** `MR.Mat`: exact (Q) matrices: `of(rows)`, `id(n)`, `add`, `sub`, `scale`, `mul` (with the dot products of each entry for display), `T`, `det` (cofactor expansion along a row with the minors, for 2×2/3×3; any n by elimination), `minor`, `cofactor`, `rref` with a step log of row operations (`swap Ri↔Rj`, `scale Ri`, `Ri + c·Rj`; Gaussian = row-echelon, Gauss–Jordan = reduced) and the solution kind (unique / none / infinite with a parametric form), `inverse` via [A | I] with steps (or singular), `solve(A, b)`, `cramer(A, b)`, `rank`, `apply(M, [x, y])`; formatters `matH(M, {aug, det, cls(i, j)})` (HTML, `span.mat` table) and `rowOpH(op)` ("R₂ → R₂ − 3R₁").
- **Linear programming** `MR.lp(constraints, objective)`: half-planes `a x + b y ≤ c` → feasible polygon vertices (exact Q), bounded/unbounded/empty, objective value at each vertex, the optimum (or "none: unbounded").
- **Partial fractions** `MR.partialFractions(N, factors)`: N a Poly, factors `[{p: Poly (linear or irreducible quadratic), m}]` → terms `[{num: Poly, den: p, power}]` (exact, by solving the coefficient system with `linSolve`) + the system rows for the steps panel; `pfH(terms)`.
- **Function behaviour**: `avgRate(f, a, b)` (exact for Poly), `incDec(p)` (intervals where a polynomial increases/decreases, local extrema from `turningPoints`), `symmetry(f)` numeric even/odd/neither for any function, `diffQuot(p, a)` → Poly in h of (p(a + h) − p(a))/h, `slopeAt(p, a)`.
- **Zeros**: `descartes(p)` (positive/negative sign changes and the possible counts), `boundTest(p, c)` (upper/lower bound by synthetic division), `bisect(f, a, b, n)` with steps.
- **Models**: `logistic(c, a, b)` → f, inflection {t, y}, `logisticFrom(points)`; `fit(kind, pts)` for kind linear / exp (y = a·bˣ via ln y) / log (y = a + b ln x) / power (y = a·xᵇ via ln–ln) → {a, b, r, r2, f, text}.
- **Conics**: `eccentricity(conic)`, focus–directrix data, `polarConic(e, p, trig: "cos"|"sin", sign)` → type, vertices, foci, directrix, a, b, c (exact when e, p rational), `rotateConic({A, B, C, D, E, F})` → angle θ (cot 2θ = (A − C)/B, exact cos θ / sin θ when they are), rotated coefficients, `discriminant` and type.
- **Parametric**: `projectile(v0, θdeg, h0, g)` → x(t), y(t), flight time, range, apex (exact where possible), `cycloid(r)`, `eliminate` is a writer's text (no rule).
- **Counting/probability**: `fact`, `nPr`, `nCr` (exists), `multiset(n, [k…])`, `probQ(fav, total)` as Q; `inclExcl(nA, nB, nAB, N)`.
- **Limits**: `ratLimit(num, den, a)` → {left, right, value | "∞" | "−∞" | "DNE", kind: "value" | "hole" | "vertical" | …} exactly (cancels common factors), `limInf(num, den, sign)` (degrees, leading coefficients), `table(f, a, side, n)` (x approaching a with 10⁻ᵏ steps, values), `pieceLimits(pieces, a)` left/right/value for piecewise functions, `continuityAt(pieces, a)` → the three conditions and the discontinuity type.
- **Drawing (MathKit)**: `k.matH(S, grid, {aug, det, cls, td})` renders a matrix whose entries are `k.vars` numbers (scrubbable) inside `span.mat`; `P.feasible(constraints, color)` shades a feasible region; `P.secant(f, a, b, color)` line through two curve points; `P.paramTrace(fx, fy, t0, t1, t, color)` curve with a moving point and direction arrows.
