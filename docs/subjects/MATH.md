# Subject card: Mathematics (Algebra II onward)

Read after `docs/universal/WRITER-CORE.md` and the cards your spec names (graph labs: `docs/categorical/PLANE.md`; worked solutions: `STEPPER.md`; drills: `QUIZ.md`).

## Standard and markup
College level, standard order and terms; each field's spec names its reference text (Algebra II ≈ OpenStax *Intermediate Algebra 2e* / *College Algebra 2e*; Trigonometry ≈ *Algebra and Trigonometry 2e* ch. 7–10; Precalculus ≈ *Precalculus 2e*). Terms as the textbook uses them: "solution set", "interval notation", "multiplicity", "end behavior", "vertical/horizontal/slant asymptote", "removable discontinuity (hole)", "one-to-one", "imaginary unit i (i² = −1)". `voice: "plain"`; `grade` like `"Grade 12 · college Precalculus"`.
All math in `<span class="m">…</span>`, variables `<i>x</i>`, real symbols × ÷ − (U+2212) · ≤ ≥ ≠ ≈ √ π ∞ ∈ ℝ ℂ ⇒ ∘. `<sup>`/`<sub>`. Stacked fraction `<span class="fr"><span>3</span><span>4</span></span>`. Radicand overline `√<span class="ov">x + 1</span>` (`.mk-ol` in labs). Displayed lines `<div class="display">a<br>b</div>`. Intervals `(−∞, 2) ∪ [5, ∞)`. Σ with limits `<span class="sig"><span>n</span><span>Σ</span><span><i>k</i>=1</span></span>`. Matrices: `<span class="mat"><table><tr><td>1</td><td>2</td></tr>…</table></span>` (square brackets drawn by CSS; `class="mat aug"` puts the bar before the last column of an augmented matrix; `class="mat det"` draws determinant bars).

## Kit: `MathKit.attach(k)` first in every math lab
It adds `k.MR` (= `window.MathRules`), `k.cplane(c, o)` (complex plane, `P.z(z, color, {vec})`) and `k.synthHTML(synth, r, upto)`. Everything else (plane, drag, vars, steps, readout, guard) is already on `k` (universal + categorical kits).

**MathRules** (`k.MR`, DOM-free, tested in `tests/math.test.js`; add what you need there, with a test):
- Exact numbers: `Q(n, d)` rationals (`Q.add sub mul div neg inv pow eq cmp lt val abs isInt`; `Q(0.75)` → 3/4), `Z(re, im)` complex (`add sub mul div conj neg norm pow ipow eq abs arg val`), `sqrtParts(72) = [6, 2]`, `sqrtQ(Q(9, 8))` → `{s, t}`, `radFrac(s, t)`, `quadRoots(a, b, c)` → `{D, kind, p, s, t, imag, values, exact}`, `gcd`, `lcm`, `divisors`, `sci(v)`.
- Polynomials `Poly([c0, c1, …])` lowest degree first: `add sub mul scale pow eval evalN fn deriv compose divmod → {q, r, steps} synth(p, r) gcd ratCandidates ratRoots realRoots roots ends fromRoots deg lead eq`; `factorPlan`, `rootTestOrder`, `synthDistractors`, `groupZeros`, `turningPoints`, `polySymmetry`, `signPattern`, `factoredStr`, `factorIntStr`, `factorStr(r, {html, integer})`, `leadStr`, `endsStr`, `monoStr`.
- Functions: `transform(f, {a, b, h, k})`, `transformPoint`, `compose`, `invert(f, y, lo, hi)`, `isOneToOne`, `sameGraph(f, g, lo, hi)`, `zeros(f, lo, hi)`, `intersect(f, g, lo, hi)`, `continuous`.
- Rational functions: `rational(num, den)` → `{holes, vas, zeros, excluded, yint, asym {type, y | poly}, f, reduced}`, `signIntervals(R)`, `asymCross(R)`, `variation(type, x0, y0)`.
- Inequalities and sets: `solveIneq(N, D, rel)` (sign chart: crit, ivs, pieces), `criticalValues`, `testValue`, `ineqSetStr`, `INEQ`, `INEQ_FLIP`; exact interval sets `RS` (`ep root ALL ge ne and or has str qh`).
- Quadratics and conics: `vertexForm(a, b, c)`, `vertexFormStr`, `shiftStr`, `sqShiftStr`, `conic({A, C, D, E, F})` → `{type, h, k, a, b, c, e, r2, p, axis, vertices, foci, focus, directrix, asymptotes, …}`, `conicGeneral(kind, {…})`, `conicStdForm`, `generalFormH`, `conicSystem(c1, c2)`, `sqrtQStr`, `pmRootStr`, `pmPairStr`.
- Systems: **`linSolve(rows)`** (exact Gauss–Jordan, any n: `{kind: "unique", x} | {kind: "none"} | {kind: "infinite"}`, rank), `elimStep`, `elim3`, `backSub`.
- Exponentials/logs: `logb`, `logExact(b, x)`, `logPoints`, `logCases`, `compound`, `compoundE`, `eDigits`, `apy`, `doublingTime`, `periodBalance`, `radicalEq`, `logSumEq`, `sameBaseX`, `quadExpRoots`.
- Sequences/series/binomial: `arith(a1, d)` / `geom(a1, r)` → `term(n) sum(n) sumInf()`, `sigma(f, lo, hi)`, `arithSolveN`, `repDecimal`, `geomExact`, `nCr`, `pascalRow`, `pascalPath`, `binomialPoly(a, b, n)`, `binomialTerm`.
- Formatters (minus is always U+2212): `qT qH polyT polyH polyStr zT zH radStr rootsStr sg supT fmtN`; `niceStep`, `ticks`, `placeLabels` (= PlaneRules), `reveal` (= LabKit.reveal).

## Lab archetypes (the spec names one per topic + its config). All of them obey the interaction rule.
- **A · Transform**: a parent curve and its image; the parameters (a, b, h, k or the topic's own) are `k.vars` numbers in the equation (`k.eqline`) **and** handles on the graph (drag the vertex/centre to set h, k; drag a second point to set a, b). Ghost parent dashed, key points mapped with `transformPoint`, labels via `P.labels`. Modes: Explore / Match (target curve, `k.guard` the parameters).
- **B · Features**: a function from a small editable family (zeros/factors as draggable points on the x-axis, coefficients scrubbable); zeros (multiplicity: cross vs touch), intercepts, asymptotes, holes, end-behaviour arrows; a trace point glued to the curve reads values; the readout lists each feature with why. Modes: Graph / Sign chart or Table.
- **C · Steps**: a stepper drives `k.stepsPanel` beside a small graph or table that changes with each step; the problem's numbers are `k.vars` (scrub a coefficient and the worked solution is redone; New problem picks a fresh exact case). `MathRules` decides correctness. Modes: Worked / Your turn (guarded).
- **D · Plane**: complex plane, conics, vectors or implicit curves with draggable defining points (foci, vertices, centre, a point on the curve gliding along it); geometry of the operation shown with arrows/segments (distances to foci, directrix).
- **E · Model**: data points (draggable) or a scenario (growth, interest, decay, sequences); the model's parameters are scrubbable numbers; fit or compare models; a curve-glued trace point reads values; the readout shows the model's numbers exactly and in context.
- **F · Triangle** (Trigonometry): the triangle to scale with draggable vertices; given parts outlined in their colours, found parts one per step (`k.stepsPanel`, `k.guard`), case readout (SAS, SSA: 0/1/2).
- **G · Matrix** (Precalculus): an editable matrix (every entry a `k.vars` number in a `span.mat` table) beside its picture: row operations as steps, a 2×2 matrix acting on the plane (drag the images of î and ĵ), determinant as signed area.
Make each lab specific to its topic within its archetype: the archetype saves plumbing, not ideas.

## Trigonometry (`web/kits/subjects/trig.js`, loaded after math.js; same `k.MR` and `MathKit.attach(k)`)
Degrees and radians both; radian answers exact (5π/6). Write `sin² θ`, `sin⁻¹ x` (also "arcsin"), θ for angles, t for unit-circle arc length; "reference angle", "coterminal", "principal value", "amplitude", "period", "phase shift", "midline", "SSA (ambiguous case)", "bearing", "resultant", "modulus", "argument", "polar form r(cos θ + i sin θ)".
**Rules** (angles are Q multiples of π: `Q(5, 6)` = 5π/6; many accept `{deg: true}`): `piT/piH`, `degQ`, `qDeg`, `qRad`, `piQ(rad)`, `normQ`, `normDeg`, `quadrant`, `axisOf`, `refAngle`, `refOf`, `coterminal`, `reduceDeg`, `dms`, `fromDms`, `degT`, `angT`; **`trigExact(fn, a)`** (all six at multiples of π/12), `exactOf`, **`sixFrom(x, y)`**, `sixRatios`, `ratioExact`, `ucPoint(q)`, `sideT`, `sqrtRatio`, `otherSinCos`, `SIGN_QUADS`; graphs y = A·fn(B(x − C)) + D: `sinusoid`, `keyPts`, `period`, `asymptotes`, `asymGenT`, `sinEq(fn, A, B, C, D, {html})` (A c3, B c2, C c1, D c4), `sameCurve`, `piFmt`; **`trigSolve(fn, k, {B, C, lo, hi})`**; **`solveTriangle({…})`** (SSS/SAS/ASA/AAS/SSA with 0/1/2), `ssaCase`, `lawFor`, `heron`, `triArea`, `sinD cosD asinD acosD`; vectors `MR.V` (`mag dir fromPolar add sub scale dot angle unit comp proj fromBearing toBearing`), `dirFix`, `tensions`; `toPolar`, `toRect`, `polarNames`, `polarFamily`, `POLAR_FAMILIES`; complex polar `MR.cplx` (`cis polar mul div pow roots`), `cisT`, `cisExact`, `exTerms`, `exZStr`, `nthRootT`.

## Precalculus (`web/kits/subjects/precalc.js`, loaded after math.js; same `k.MR` and `MathKit.attach(k)`)
Spec: `web/TREE-SPEC-PRECALCULUS.md` (OpenStax *Precalculus 2e*). Every lab follows the interaction rule (`docs/categorical/PLANE.md`): name your handles and scrubbable numbers as the spec does.
**Rules** (tested in `tests/precalc.test.js`; exact Q unless noted):
- Matrices `MR.Mat`: `of`, `dims`, `id`, `zero`, `eq`, `add`, `sub`, `scale(c, A)`, `mul(A, B)` (null when undefined), `dotTerms(A, B, i, j)`, `T`, `minor`, `cofactor`, `det`, `expand(A, "row"|"col", idx)` → `{terms: [{i, j, a, sign, minor, M, term}], det}`, **`rref(A, {aug, reduced})`** → `{steps: [{op, M, pivot, phase}], M, rank, pivots, kind: "unique"|"none"|"infinite", x, free, param}` (op `{type: "swap", i, j}` / `{type: "scale", i, c}` / `{type: "add", i, j, c}` = Ri → Ri + c·Rj; pivots prefer a row with ±1; `reduced: false` stops at row-echelon form with leading 1s), `rank`, `solve(A, b)`, `inverse(A)` → `{inv | null, singular, steps}`, `cramer(A, b)` → `{D, Ds, x}`, `apply(M, [x, y])` (numbers), `solText(rrefResult)` ("(1, −1, 2)", "∅", "(4 − 2s − 3t, s, t)"). Text/HTML: `rowOpT(op, html)` ("R₂ → R₂ − 3R₁"), `matH(M, {aug, det, cls(i, j), cell(i, j, v)})`.
- `lp(constraints, {a, b})` with constraints `[{a, b, c, rel: "<=" | ">="}]` → `{empty, bounded, vertices: [{x, y, q: [Q, Q], z}], polygon, max, min: {z, at} | null (unbounded)}`.
- `partialFractions(N, [{p, m}])` → `{poly (quotient if improper), terms: [{num, den, power, names}], rows (coefficient system, highest power first), unknowns, sol}`.
- Behaviour: `avgRate(f | Poly, a, b)`, `incDec(p)` → `{ivs: [{lo, hi, dir}], ext: [{x, q, y, kind}]}`, `symmetry(f)` ("even" | "odd" | "neither"), `diffQuot(p, a)` (Poly in h), `slopeAt(p, a)`.
- Zeros: `descartes(p)` → `{pos, neg, posCounts, negCounts, zeroRoot}`, `boundTest(p, c)` → `{upper, lower, row, synth}` (false = test inconclusive), `bisect(f, a, b, {n, tol})` → `{steps, root}`.
- Models: `logistic(c, a, b)` → `{f, y0, inflection}`, `logisticWhen(c, a, b, y)`, `fit(kind, pts)` (kind linear | exp | log | power) → `{a, b, r, r2, f, X, Y}` (numbers; null if a point is outside the model's domain).
- Conics: `eccentricity(conic(...))` → `{e, e2, directrices}`, `polarConic(e, p, "cos"|"sin", ±1)` → `{type, directrix, vertices, center, a, c, b2, r(θ)}`, `rotateConic({A, B, C, D, E, F})` → `{disc, type, theta, cot2, cos, sin, coef (numbers), exact: {cos2th, sin2th, …} and coefQ {A, C} when exact}`.
- Parametric: `projectile(v0, deg, h0, g)` → `{x(t), y(t), vx, vy, T, range, apex}`, `cycloid(r, d)`.
- Counting: `fact`, `nPr`, `nCr`, `multiset(n, [k…])`, `probQ(fav, total)`, `inclExcl(nA, nB, nAB, N)` (throws past 2⁵³ rather than lose exactness).
- Limits: `ratLimit(num, den, a)` → `{kind: "value"|"hole"|"vertical", value, left, right, n1, d1}`, `limInf(num, den, ±1)`, `limTable(f, a, ±1, n)`, `pieceAt(pieces, a)`, `continuityAt(pieces, a)` → `{defined, limExists, equal, type}` with pieces `[{p: Poly | f, lo, hi, loIn, hiIn}]`.
**Drawing**: `k.matH(S, grid, {aug, det, cls(i, j) (number colour), td(i, j) (cell class)})` (a matrix whose entries are `k.vars` keys, so the learner scrubs/types each entry; fixed entries may be Q/numbers/html), `P.feasible(constraints, fill, stroke)`, `P.secant(f, a, b, color, {seg})` (returns the slope), `P.paramTrace(fx, fy, t0, t1, t, color, {arrows})` (returns the point at t).
**Checks**: `from precalc import *` (`checks/_lib/precalc.py`; docstring lists all): `mat rref_of det_of inv_of solve_system cramer row_op lp_corners partial avg_rate diff_quot slope_at extrema inc_dec descartes upper_bound_ok logistic_t fit_* polar_conic rotation_angle rotated conic_type projectile perm comb multiset prob lim lim_inf continuous_at induction_ok`.
